## 中文简介（约 260 字，可直接用）

Unity 项目用久了，总会攒下一堆说不清的问题：场景里红色的 Missing、法线图被当成颜色贴图导
致光照发灰、贴图勾了 Read/Write 让内存翻倍、同一张图在工程里存了四份、`.meta` 被
`.gitignore` 忽略后引用全部失效。

UnityGuard 是一个本地运行的 Windows 小工具，只做两件事：**体检**和**安全整理**。

体检是完全只读的，几秒钟扫完，把 20 多类问题按严重程度列出来，每条都告诉你"为什么会这样、
怎么改"。整理则是把体检结论变成可执行的计划：修导入设置、按类型归档、把没人引用的重复文件
隔离到 Unity 忽略的目录、改名或移动文件（文件夹也行）。每一条变更都会先让你预览，执行时会
同步移动 `.meta`、逐条校验 GUID 没有变化，并写一份回滚日志——**随时可以一键撤销，回滚到
逐字节一致的状态**。

不需要安装 Python，不需要打开 Unity，双击就能用。当前版本是**免费完整版**，所有功能都不限量。

## English introduction (~150 words)

Unity projects accumulate quiet problems: red "Missing" references, normal maps imported as
colour textures, Read/Write left on textures, the same sprite stored four times, and `.meta`
files lost to a careless `.gitignore` — taking every GUID with them.

**UnityGuard** is a small local Windows tool with two jobs: **audit** and **safe cleanup**.

The audit is strictly read-only and takes seconds. It reports 20+ classes of problems by
severity, and explains why each one matters and how to fix it. Cleanup turns those findings into
a plan you review first: fix importer settings, sort assets by type, quarantine unreferenced
duplicates into a folder Unity ignores, or rename/move files (folders included). When you apply,
it moves `.meta` files together with their assets, verifies the GUID has not changed, and writes
a rollback journal — so you can undo everything, byte for byte, at any time.

No Python install, no Unity running, just double-click. The current build is the **complete free
edition**, with no feature limits.

## 安全承诺（写进网页有说服力）

- 体检**只读**，不改任何文件；
- 执行前必须显式确认，且支持 `--dry-run` 预览；
- 每次改动都同步处理 `.meta`，并**断言 GUID 未变**；
- 检测到 Unity 正在打开工程时**拒绝执行**；
- 所有变更写入回滚日志，**随时一键撤销**；
- 绝不覆盖已存在的文件（含仅大小写不同）。

## 系统要求

- Windows 10 / 11，64 位
- 约 40 MB 磁盘空间
- 不需要安装 Python，不需要 Unity 授权

## 关于杀毒软件误报（务必先看）

本程序用 PyInstaller 打包。这类"把 Python 解释器塞进 exe"的产物，会被**少数几个引擎**
按"打包 / 自解压行为"报成可疑，而不是命中了真实病毒特征：

| 检测引擎 | 判定 | 说明 |
| --- | --- | --- |
| SecureAge | Malicious | 对未签名的 PyInstaller 程序有长期高误报率 |
| Skyhigh SWG | BehavesLike.Win64.Backdoorvc | 行为沙箱，看到"自带解释器"就报，标的是 BehavedLike 而非病毒家族 |

实测：2026-11-24 上传 VirusTotal，**70 个引擎中 2 个报警，68 个未检出**
（微软、卡巴斯基、ESET、BitDefender、CrowdStrike 均未检出）。

程序的真实行为：

- **不联网**，没有任何网络请求；
- **不写注册表**，不在系统目录留文件；
- 只读写你亲自选择的 Unity 工程文件夹，以及其中的 `.unityguard/` 回滚日志。

如果你想自己验证：

1. 核对文件哈希（同目录 `SHA256SUMS.txt`）：
   `Get-FileHash .\UnityGuard.exe -Algorithm SHA256`
2. 或者用源码自行构建，再比对哈希：
   ```
   pip install pyinstaller
   python tools/build_exe.py
   ```

如果安全软件仍然拦截，把这个文件夹加入白名单即可；程序不需要管理员权限。

## 已知限制（诚实写出来反而更可信）

- 二进制序列化（Unity 5.x 默认）的工程，引用分析会主动停用并提示，不会瞎报"未使用"；
- Addressables 的"地址键"是字符串，改名不会自动同步，需人工检查；
- 贴图用途、命名风格属于启发式判断，报告里一律标"疑似"；
- 目前只支持文件与文件夹的重命名/移动，不支持删除。

## 适合谁

独立开发者、外包美术、买了很多 Asset Store 资源包的人、接手别人工程的人。

## 不太适合

需要联网协作/权限管理的团队（这是纯本地工具）；想要"一键自动整理整个项目且完全不看预览"的人
——它坚持让你先看计划。

### Antivirus false positives

This build is packaged with PyInstaller, and a couple of engines (notably SecureAge and
Skyhigh SWG) flag such self-extracting executables on *packing behaviour*, not on a real
virus signature - Skyhigh's label is literally `BehavesLike.*`. On 2026-11-24, VirusTotal
reported **2 detections out of 70**; Microsoft, Kaspersky, ESET, BitDefender and CrowdStrike
all reported clean.

The program makes no network requests, writes no registry keys, and only touches the Unity
project folder you select (plus its `.unityguard/` rollback journal). Verify with the SHA-256
list shipped next to the exe, or build it yourself with `python tools/build_exe.py`.
